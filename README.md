# AgileCopilot

A 7-day proof-of-concept: the connective layer over Jira and Confluence that
turns a Scrum Master's manual reporting/documentation upkeep into an
automated background process, gives them one place ("Ops Hub") to see
everything on their plate, and gets the Product Owner the sprint outcome —
velocity, quality, what shipped — without asking anyone.

See [`spec.md`](./spec.md) for the full product spec, and
[`UI-REDESIGN-SPEC.md`](./UI-REDESIGN-SPEC.md) for the functional/content spec
this build's UI can be redesigned from. Planning artifacts (brief, PRD,
architecture spine, epics) live under `_bmad-output/planning-artifacts/`.

## Stack

Next.js 14 (App Router) + TypeScript + Tailwind CSS. No database — three JSON
fixture files under `data/` stand in for Jira/Confluence/ops-inbox exports. No
auth, no outbound integrations — every report/draft is copied by the user,
never sent automatically. (A real database is planned for a future phase.)

## Getting started

```bash
npm install
cp .env.example .env.local   # optional — see below
npm run dev
```

Open http://localhost:3000 for the public landing page, or go straight to
http://localhost:3000/overview for the signed-in home screen — Ops Hub,
Report, Process Health, Doc Linker, and Performance Import are all in the nav.

## Environment variables

Optional — the POC runs and demos fully without it:

- `GEMINI_API_KEY` — when set, the narrative report, delegation suggestions, and
  drafted emails/reminders are generated by the Gemini API. **When unset**, each
  of those falls back to a deterministic, template-based generator built from the
  same fixture data — the app is fully functional and demoable without a key.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build (typecheck + lint)
- `npm start` — run the production build
